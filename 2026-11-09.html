📈 本周趋势洞察

1. 「运行环境」成了独立商品，比价单位从 token 换成「agent 跑一个月多少钱」
Kimi Hosted Agents 把云沙箱按每小时0.072元、插件按次单独列项，Perplexity 把常驻 agent 绑到200美元档位并按 credits 扣，微软 Foundry 的托管 harness 12月1日起按资源用量计费。模型单价还在降，但一个 agent 真实跑一个月的总成本，越来越由沙箱时长、工具调用次数、上下文压缩效率决定——继续只盯 token 报价做选型，会算错账。
2. 常驻型 agent 全面替代一次性对话，但需求端还没跟上
Perplexity 的 Teammates 用一条永不关闭的线程加独立云电脑，DeepSeek Super-agent 用 Watchdog 盯任务有没有跑偏，Airbnb 干脆不用聊天框、改成实时拼装的生成式界面。共同点是 agent 自己判断什么时候该动、该输出什么形态。但 Uber 那组数据是清醒剂：万圣节周3.2亿次出行与订单里，只有4单来自 AI agent——能持续干活和有人愿意让它干，是两件事。
3. 跨境电商 AI 从「帮你写」转向「帮你盯，并且留证据」
TikTok Shop 的 Product Growth Opportunities 给每条建议标上预计能多几单，Amazon 的 Reporter Assistant 在提交前就把表单错误挑出来，cx-listing-playbook 每次改动都留前后对照加平台回执，ASIN 透视镜把竞品三年的 listing 演变拉成时间线。卖家缺的早已不是生成能力，而是可追溯、可回滚、能验证效果的动作记录——这也是今年这批工具和去年那批「一键生成」最本质的区别。
