适合谁：想体验「AI 替我跑腿」的普通用户，以及关注个人 Agent 产品形态的产品经理。

HyperFrames 48k+ Stars
HeyGen 开源的 AI 原生视频渲染框架：写 HTML 就能渲染出像素级一致的专业视频，Agent 天生就会写 HTML，等于给 Agent 配了一个免费视频生产引擎
🖥️ 内容生产 🏗️中型框架
📋 使用说明
解决什么问题：视频生成 API 按量收费贵且不可控，剪辑软件上手门槛高。HyperFrames 用确定性渲染解决：同一份 HTML 在任何机器上逐帧 100% 一致，适合批量化生产，且无 React、无专有 DSL，AI 编码 Agent 天然会用。
怎么用：用 data-start、data-duration、data-track 等属性在 HTML 元素上声明时间轴，底层 Puppeteer + FFmpeg + Chrome BeginFrame API 渲染成 MP4；支持 GSAP、Lottie、Three.js、透明视频输出，可跑成 HTTP 渲染服务器；官方提供 Claude Code、Cursor、Codex 的 skills，npx skills add heygen-com/hyperframes 即可让 Agent 学会写视频。
适合谁：做批量短视频、产品宣传、数据可视化视频的开发者和内容团队，想摆脱按量付费视频 API 的创业者。
Graphify 100k+ Stars
YC S26 项目，一句话把整个代码库、文档、PDF 变成可查询的知识图谱，AI 不再瞎 grep，沿着真实调用关系追答案，全程本地零遥测
📡 信息与工作流提效 🏗️中型框架
📋 使用说明
解决什么问题：AI 助手读代码靠 grep 逐文件翻，RAG 靠相似度猜来源，都不靠谱。Graphify 用 tree-sitter 把代码库解析成知识图谱——节点是函数和类型，边是调用和继承，AI 直接走图谱，每一跳都有出处，图谱建一次持久化复用。
怎么用：在 Claude Code、Cursor、Codex 等 17+ 工具里输入 /graphify . 即可建图，支持代码、文档、PDF、图片、视频；纯本地解析、零 LLM、零遥测，MIT 协议个人商用全免费。
适合谁：接手大型陌生代码库的开发者、需要 AI 深度理解私有代码库的团队、对隐私敏感的企业。
