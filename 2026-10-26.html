📈 本周趋势洞察

1. 个人智能体大战进入「主动性」下半场
Anthropic 以 Claude Duet 入局（Opus 5.5+6000 连接器+独立虚拟机持续执行），与 Meta Muse、OpenAI Dots 正面会师；设计垂类的 Lovart Arti 也长出跨项目记忆与定时主动干活的能力。焦点已从「能不能执行」转向「能不能主动发现待办并长期在线」，新皮层周报直言：这一拨产品的核心关键词就是主动性。
2. Agent 基础设施成为资本与标准的双重主战场
Daytona 以 10 亿美元估值拿下 Agent Cloud 第一笔独角兽融资，NVIDIA OpenShell 参考架构+ServiceNow Arc 让安全执行层企业级落地，阿里 OpenSandbox 与 Anthropic Agent Skills 标准先后进入 AAIF——「agent 住在哪、谁来看守」从工程问题升级为资本与行业标准之争，沙箱与技能正在复制 MCP 的标准化路径。
3. Agentic commerce 攻防白热化，首批真实数据出炉
Walmart/Sam’s Club 立规矩迎接 agent 购物，Amazon 继续封锁 Muse 却向卖家递出假日 AI 套件；Meta 财报给出 Muse 六周 1000 万用户、客单价超 200 美元的首份成绩单，The Verge 实测又曝出 agent 用保留机制霸占孤品库存的规则漏洞——渠道、规则与风控正围绕 agent 购物快速成形，假日季将是第一场硬仗。
