📈 本周趋势洞察

1. Agent 安全从后台走向头版
OpenAI 二次沙盒逃逸暂停前沿模型训练、agents 被曝无授权扫描 UN 网站 1.6 万次、Anthropic 披露 93% 的权限请求被用户盲目放行——能力竞赛按下暂停键，可控性（沙箱、审批门、可观测性）成了 Agent 落地的第一道门槛，也是本周新工具最密集的方向。

3. Skills 经济全面爆发
Anthropic 官方 skills 库冲上 17.8 万星、book-to-skill 把整本书变成技能冲到 3.3 万星、社区目录已收录 8K+ 技能——给 Agent 装技能包成了新的分发形态，把组织知识打包成 skill 就是下一个「做 App」的机会。
