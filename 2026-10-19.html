📈 本周趋势洞察

1. 「AI 重写商业软件」从猎奇变成现象级
REA 一周再涨约 25 万星、总星数逼近 30 万并发布 v6.5.0；ArtCraft 用 Claude Opus 5.5 净室重写的 Adobe+Office 13 件套一周 2 万星，PhotoCraft 单周新增 4.3 万星；CLI-Anything 让任意软件一步 CLI 化——「让 agent 理解并重建一切软件」正从猎奇演示变成工程化能力，36kr 直接宣布「软件这门生意结束了」，版权与合规争议同步升温。
2. Agent 通行权两极分化，agentic commerce 管道加速成形
The Verge 报道 Amazon、达美航空、摩根大通、嘉信集体封锁第三方 agent，Yelp 转为付费授权；同一周 Shopify 把 10 亿商品默认开放给任意购物 agent 并打通 Shop Pay 结账、蚂蚁国际 Wyn 用 A2A 互联跨境资金生态——「agent 能不能进门」正成为新的商业筹码，开放与封堵的分化里，Q4 假日季将是第一场 agent 真实参与的购物大战。
3. 个人 Agent 大战开打，单位智能成本继续跳水
阿里官宣千问Go!、字节豆包 Spell、腾讯元宝助手与 Handy、Meta Muse Wonder（Active Memory+Focus）、GPT-6 Astra Pro 多智能体并行——头部厂商把「专属个人 agent」当成下一代入口；同时 DeepSeek 1017 版 token 消耗再降 50%+、搜索每千次 5 元，单位智能成本持续下探，多模型编排从优化项变成默认架构。
